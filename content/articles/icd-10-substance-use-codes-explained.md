A chart says "alcohol use disorder, moderate," and the code on the record is F10.20, "Alcohol dependence, uncomplicated." The word "dependence" sits in the code title while the chart says "use disorder." The same chart, a month later, says "in early remission," and the code is F10.21.

The codes are not arbitrary. Every character carries meaning, and once you can read them you can check a code against the chart. This article takes apart the ICD-10-CM codes for substance use disorders, category by category and character by character, and shows how they map to DSM-5 severity.

It explains classification. It is not clinical or billing advice. Diagnosis is the clinician's judgment; verify code selection with your coder or billing lead.

## Which code set this describes

This article uses the **ICD-10-CM FY 2027** code set, effective October 1, 2026 through September 30, 2027. NCHS says "FY27 ICD-10-CM codes should be used for healthcare services provided from October 1, 2026, through September 30, 2027" ([NCHS, ICD-10-CM files](https://www.cdc.gov/nchs/icd/icd-10-cm/files.html)). The Tabular List is in [CDC's FY 2027 release](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/icd10cm-tabular-2027.pdf), and CMS hosts the same files and the [guidelines](https://www.cms.gov/files/document/fy-2027-icd-10-cm-coding-guidelines.pdf) on its [ICD-10 page](https://www.cms.gov/medicare/coding-billing/icd-10-codes).

Did anything change this year? We compared the FY 2027 Tabular List for categories F10 through F19 against the FY 2026 file. The F10 to F19 section is identical, and the FY 2027 Tabular addenda list no additions, deletions or revisions to F1x codes. The Alphabetic Index addenda do move some pointers: opioid-induced anxiety, depressive and sexual dysfunction entries change from F11.988, F11.94 and F11.981 to F11.288, F11.24 and F11.281, and "Korsakoff, alcoholic" changes from F10.26 to F10.9-, with a "with dependence" subentry at F10.2-. Alcohol-related sexual dysfunction gains entries at F10.181 and F10.281 ([Index addenda](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/icd10cm-addenda-2027.zip)). The coding guideline for substance disorders, Section I.C.5.b, reads the same as in the October 2025 guidelines. We compared text, not claims behavior, so confirm with your coder.

## The chapter: F10 to F19

The block is titled "Mental and behavioral disorders due to psychoactive substance use (F10-F19)." Each three-character category is a substance family ([Tabular List, F10-F19](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/icd10cm-tabular-2027.pdf)):

| Category | Substance family |
|---|---|
| F10 | Alcohol |
| F11 | Opioid |
| F12 | Cannabis |
| F13 | Sedative, hypnotic, or anxiolytic |
| F14 | Cocaine |
| F15 | Other stimulant |
| F16 | Hallucinogen |
| F17 | Nicotine |
| F18 | Inhalant |
| F19 | Other psychoactive substance |

Two details trip people up. F17 holds only nicotine dependence (F17.2-), with no abuse or unspecified-use branch, and its Excludes1 note sends "tobacco use NOS" to Z72.0, a code whose only inclusion term is "Tobacco use NOS" (not a use disorder). And F15, "other stimulant," lists amphetamine-related disorders and caffeine under its Includes note, while cocaine has its own category, F14.

## Reading a code, one character at a time

Take F10.231. Position by position:

1. **F**: the mental, behavioral and neurodevelopmental chapter.
2. **F1**: the psychoactive substance block.
3. **F10**: the substance, here alcohol.
4. **F10.2**: the pattern. In the Tabular List, 1 is abuse, 2 is dependence and 9 is use, unspecified. There is no F10.0 in FY 2027.
5. **F10.23**: what accompanies the pattern. The fifth character names the condition: 0 uncomplicated, 1 in remission, 2 intoxication, 3 withdrawal, then the induced disorders (4 mood, 5 psychotic, and so on).
6. **F10.231**: a sixth character on some codes, adding detail. Under withdrawal, 0 is uncomplicated, 1 is withdrawal delirium, 2 is withdrawal with perceptual disturbance and 9 is unspecified.

So F10.231 reads "Alcohol dependence with withdrawal delirium."

Branches differ by substance: opioid withdrawal stops at five characters (F11.23), alcohol withdrawal runs to six. A shorter header such as F10.2 is a heading with more specific codes beneath it. Look up the full code instead of assuming a pattern from another substance.

### Character four: use, abuse or dependence

Abuse (1), dependence (2) and use, unspecified (9) are three distinct branches, and each carries an Excludes1 note against the other two. The Official Guidelines define an Excludes1 note as "NOT CODED HERE!" and say the excluded code "should never be used at the same time as the code above the Excludes1 note," with an exception for unrelated conditions ([Section I.A.12.a](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/ICD-10-CM-October-1-2026-FY27-Guidelines.pdf), pp. 9 to 10).

The guidelines turn that into a hierarchy. When documentation refers to more than one pattern for the same substance, "only one code should be assigned," by these rules ([Official Guidelines FY 2027, Section I.C.5.b.2](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/ICD-10-CM-October-1-2026-FY27-Guidelines.pdf), p. 43):

- Use and abuse both documented: abuse.
- Abuse and dependence both documented: dependence.
- Use, abuse and dependence all documented: dependence.
- Use and dependence both documented: dependence.

### Character five: what comes with it

The fifth character is where intoxication, withdrawal, remission and the substance-induced disorders live. A few things to know.

Intoxication and withdrawal are separate branches. In opioid dependence, F11.22 (intoxication) and F11.23 (withdrawal) each carry an Excludes1 note pointing at the other. Alcohol is different: F10.22 and F10.23 carry Excludes2 notes against each other, which the conventions say allow both codes together. Ask your coder how the notes apply when documentation describes both in one episode.

Induced disorders are named for what they induce: for alcohol dependence, mood (4), psychotic (5), persisting amnestic (6) and persisting dementia (7), with anxiety, sexual dysfunction and sleep disorders as sixth-character detail under 8. Opioids and cannabis have fewer of these, so check the specific category.

Remission is its own character. The guideline says selecting an "in remission" code "requires the provider's clinical judgment and are assigned only on the basis of provider documentation" ([Section I.C.5.b.1](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/ICD-10-CM-October-1-2026-FY27-Guidelines.pdf), p. 43). The code follows what the provider documented.

Unspecified use (the 9 branch) has a narrow rule. The F1x.9- codes "are to be used only when the psychoactive substance use is associated with a substance related disorder... or medical condition, and such a relationship is documented by the provider" ([Section I.C.5.b.3](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/ICD-10-CM-October-1-2026-FY27-Guidelines.pdf), p. 44). It is not a catch-all for "client uses something."

## How DSM-5 severity maps to the codes

This section draws on DSM-5 sources, so check the severity wording against your DSM-5-TR. DSM-5 folded two older diagnoses into one. APA's fact sheet says "Substance use disorder in DSM-5 combines the DSM-IV categories of substance abuse and substance dependence into a single disorder measured on a continuum from mild to severe," and that mild "requires two to three symptoms from a list of 11" ([APA, DSM-5 fact sheet: Substance-Related and Addictive Disorders](https://www.psychiatry.org/getContentAsset/1c36ce25-0d04-425c-8de9-b39e5781024e/dfc3d011-8f63-43f6-9ed8-4b444333a1d0/APA-DSM5-Substance-Use-Disorder.pdf?language=en)). NIAAA, citing the same criteria for alcohol, gives the bands as "mild (two to three criteria), moderate (four to five criteria), or severe (six or more criteria)" ([NIAAA, Understanding Alcohol Use Disorder](https://www.niaaa.nih.gov/publications/brochures-and-fact-sheets/understanding-alcohol-use-disorder)).

ICD-10-CM never merged abuse and dependence, so the code set bridges them with inclusion terms written into the Tabular List. APA describes the relationship generally: "The codes that appear in DSM are the ICD codes that are equivalent to the DSM diagnoses" ([APA, Coding and Recording Procedures](https://www.psychiatry.org/getContentAsset/136283f7-0002-4ea7-ac1f-a6eb57647b4c/dfc3d011-8f63-43f6-9ed8-4b444333a1d0/APA-DSM5TR-Coding?language=en)). The bridge itself reads:

| DSM-5 severity | ICD-10-CM branch | Example |
|---|---|---|
| Mild | Abuse (F1x.1-) | F10.10, "Alcohol abuse, uncomplicated," includes "Alcohol use disorder, mild" |
| Moderate | Dependence (F1x.2-) | F10.20, "Alcohol dependence, uncomplicated," includes "Alcohol use disorder, moderate" |
| Severe | Dependence (F1x.2-) | F10.20, same entry, includes "Alcohol use disorder, severe" |

Source for every row: [Tabular List, F10.10 and F10.20](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/icd10cm-tabular-2027.pdf). The same pattern repeats across the other substances, with one exception: nicotine has no abuse branch, so all three tobacco severities sit under F17.200. Opioid use disorder, mild is an inclusion term at F11.10, and moderate or severe sit at F11.20.

What follows from that table:

- **Moderate and severe collapse into one code.** The code cannot tell them apart. Severity lives in the clinician's documentation.
- **"Dependence" in a code description is a classification label, not a second diagnosis.** APA said of the older DSM-IV diagnosis that "the diagnosis of dependence caused much confusion," and that "dependence can be a normal body response to a substance" (same APA fact sheet). The Tabular List lists "Opioid use disorder, moderate" and "severe" under F11.20, "Opioid dependence, uncomplicated." Our reading: the word "dependence" in the code title is the classification's label for that branch, and the use disorder terms beside it show what the code stands for.
- **Remission follows the same split.** The guideline says "Mild substance use disorders in early or sustained remission are classified to the appropriate codes for substance abuse in remission, and moderate or severe substance use disorders in early or sustained remission are classified to the appropriate codes for substance dependence in remission" (Section I.C.5.b.1). Early and sustained remission share one code. In the Tabular List, F10.21 lists all four moderate and severe, early and sustained combinations under a single entry.

## Worked examples

All descriptions below are from the FY 2027 Tabular List. The chart language is synthetic.

**F10.20, Alcohol dependence, uncomplicated.** Chart: alcohol use disorder, moderate. No intoxication, withdrawal or induced disorder documented. The fifth character 0 means none of the other branches applies.

**F10.21, Alcohol dependence, in remission.** Chart: alcohol use disorder, severe, in sustained remission. Provider documentation drives it, per the guideline above.

**F11.23, Opioid dependence with withdrawal.** Chart: opioid use disorder, moderate, with documented withdrawal. Five characters; the alcohol equivalent, F10.23-, needs a sixth.

**F10.231, Alcohol dependence with withdrawal delirium.** Chart: alcohol use disorder, severe, with withdrawal delirium documented by the provider.

**F12.10, Cannabis abuse, uncomplicated.** Chart: cannabis use disorder, mild. The Tabular List lists that exact term under F12.10.

**F17.210, Nicotine dependence, cigarettes, uncomplicated.** Chart: nicotine dependence, cigarettes. F17 has no abuse branch. The Tabular List puts "Tobacco use disorder, mild," "moderate" and "severe" all under F17.200, "Nicotine dependence, unspecified, uncomplicated," so every DSM-5 severity maps to the same dependence code. F17.210 adds the product, cigarettes.

**F10.20 plus a medical code.** Guideline Section I.C.5.b.4 covers medical conditions caused by substance use: "Medical conditions due to substance use, abuse, and dependence are not classified as substance-induced disorders." Its example is alcoholic pancreatitis due to alcohol dependence. Assign the pancreatitis code from K85.2 "and the appropriate code from subcategory F10.2, such as code F10.20," and "it would not be appropriate to assign code F10.288" (p. 44). Check how your coder sequences the pair.

One more optional code. Category F10 carries a note to use an additional code from Y90.- for blood alcohol level, if applicable. The guidelines say a Y90 code "may be assigned when this information is documented and the patient's provider has documented a condition classifiable to category F10," and that the level "does not need to be documented by the patient's provider in order for it to be coded" ([Section I.C.5.b.5](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/2027/ICD-10-CM-October-1-2026-FY27-Guidelines.pdf), p. 44, which cross-references Section I.B.14 for documentation by clinicians other than the provider).

## What the code does not do

A code names a diagnosis category. It does not record criteria met, symptom count beyond the mild versus moderate-or-severe line, or why the clinician chose a severity. That stays in the note. Which codes a payer accepts, and in what order, is a payer and coder question. Bring this article to your billing lead, not instead of them.

We left out Part 2 confidentiality, which sits under different rules ([42 CFR Part 2 and AI documentation](/articles/ai-scribes-42-cfr-part-2/)), and we did not cover the older ICD-10 chapters or DSM-5-TR criteria text. For those, read the sources directly.
